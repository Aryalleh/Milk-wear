# پرینت‌ایجنت لبنیات 

برنامهٔ کوچکی که **کنار پرینتر حرارتی ۸۰م‌م (ESC/POS)** اجرا می‌شود، به سرور وصل می‌شود،
کارهای چاپ (بارنامه/فاکتور) را از صف می‌گیرد و چاپ می‌کند.

## چطور کار می‌کند؟
```
مرورگر ─ثبت سفارش/فروش─► سرور (صف print_jobs)
                              ▲  │
        این ایجنت ───poll────┘  └──► تصویرِ آمادهٔ سند را می‌گیرد
        (سرور همان تمپلیت HTML فاکتور/بارنامه را با کروم بی‌سر به PNG رندر می‌کند)
        و آن را روی پرینتر چاپ می‌کند، سپس done می‌فرستد.
```
- خروجی **مو‌به‌مو همان طراحی HTML** است (به‌همراه QR)، چون سرور خودِ تمپلیت را رندر می‌کند؛
  ایجنت هیچ چیدمانی انجام نمی‌دهد و فقط تصویر را چاپ می‌کند.
- ایجنت فقط **اتصال خروجی** به سرور می‌زند؛ هیچ پورتی روی پرینتر یا شبکهٔ شما باز نمی‌شود،
  پس حتی اگر سرور روی اینترنت باشد و پرینتر پشت مودم خانگی، کار می‌کند.
- QR بارنامه به **فاکتورِ همان سفارش** اشاره می‌کند و داخل تصویر چاپ می‌شود.

> نیازمندیِ سرور: کروم برای رندر. یک‌بار روی سرور: `npx puppeteer browsers install chrome`.

## نصب
نیازمند Python 3.9+ .

```bash
pip install -r requirements.txt
python print_agent.py
```
بعد از اجرا، مرورگر را روی **پنل مدیریت** باز کنید و همهٔ تنظیمات را از آنجا انجام دهید:

```
http://localhost:7000        # یا http://<آی‌پی-دستگاه>:7000 از یک سیستم دیگر در شبکه
```

> نیازی به ساختِ دستیِ `.env` نیست؛ تنظیمات در `config.json` ذخیره می‌شود. (فایل `.env`
> فقط برای مقداردهیِ اولیه در اولین اجرا خوانده می‌شود و همچنان پشتیبانی می‌شود.)

## پنل وب مدیریت
از پنل می‌توانید بدونِ ویرایشِ دستیِ فایل:
- **آدرس سرور، توکن، شناسهٔ ایجنت و فاصلهٔ poll** را تنظیم کنید.
- نوع پرینتر را انتخاب کنید و:
  - **USB**: با دکمهٔ «یافتن پرینترهای USB» دستگاه‌های متصل را ببینید و انتخاب کنید
    (Vendor/Product ID خودکار پر می‌شود)؛ دکمهٔ «رفع دسترسی USB» قانون udev را می‌سازد.
  - **شبکه (LAN)**: با «اسکن شبکه» کلِ ساب‌نت را برای پرینترهای شبکه جست‌وجو کنید
    (پیش‌فرض ۹۱۰۰) و از فهرست انتخاب کنید.
  - **سریال**: پورت‌های `/dev/ttyUSB*`/COM را لیست و انتخاب کنید.
- **چاپ آزمایشی** بگیرید و وضعیتِ اتصال را زنده ببینید.

پورت پنل با `PANEL_PORT` و محدودکردن دسترسی با `PANEL_HOST=127.0.0.1` قابل تنظیم است.
> امنیت: پنل احراز هویت ندارد؛ فقط در شبکهٔ محلیِ مطمئن باز بگذارید یا با `PANEL_HOST=127.0.0.1`
> به همان دستگاه محدود کنید.

### توکن ایجنت
از برنامه: **تنظیمات ← چاپ و سفارش‌گیری ← پرینت‌ایجنت** توکن را کپی و در `AGENT_TOKEN` بگذارید.

### فونت فارسی
فونت **Vazirmatn** همراه ایجنت است (`fonts/Vazirmatn-Regular.ttf`، از نوع variable که وزن
bold را هم پوشش می‌دهد). اگر خواستید فونت دیگری بگذارید، مسیرش را در `FONT_REGULAR` تنظیم کنید.

## اتصال پرینتر (`PRINTER_TYPE`)
| نوع | تنظیمات لازم | توضیح |
|-----|--------------|-------|
| `file` | — | **حالت تست**: به‌جای چاپ، هر سند را در `out/*.png` ذخیره می‌کند. برای بررسی ظاهر قبل از اتصال پرینتر عالی است. |
| `network` | `PRINTER_HOST`, `PRINTER_PORT` (۹۱۰۰) | پرینتر با پورت اترنت/Wi-Fi. |
| `usb` | `PRINTER_USB_VENDOR`, `PRINTER_USB_PRODUCT` | با `lsusb` (لینوکس) یا **Zadig** (ویندوز، درایور WinUSB/libusb) شناسه‌ها را پیدا کنید. |
| `serial` | `PRINTER_SERIAL_DEV`, `PRINTER_BAUD` | پرینتر سریال/COM. |

`PRINTER_WIDTH`: عرض چاپ به نقطه. برای ۸۰م‌م معمولاً **۵۷۶** (بعضی مدل‌ها ۵۱۲). اگر سمت راست بریده شد، ۵۱۲ را امتحان کنید.

## اجرای دائمی
- **لینوکس / رزبری‌پای**: یک سرویس `systemd` بسازید یا `python print_agent.py &` را در استارتاپ بگذارید.
- **ویندوز**: میان‌بر برنامه را در `shell:startup` بگذارید، یا با **NSSM** به‌صورت سرویس اجرا کنید.

## عیب‌یابی
- **`requires a usb library to be installed`**: کتابخانهٔ `pyusb` نصب نیست →
  `pip install -r requirements.txt` (حالا `pyusb` در آن هست).
- **USB `Access denied` (لینوکس)**: دسترسیِ کاربر به دستگاه نیست. دکمهٔ «رفع دسترسی USB»
  در پنل، یا اسکریپت `scripts/setup-usb.sh 0xVID 0xPID` قانون udev را می‌سازد. سپس پرینتر را
  جدا/وصل کنید. اگر `No backend available` دیدید، `libusb` نصب نیست
  (`sudo apt install libusb-1.0-0`).
- **USB `Resource busy`**: درایور کرنل پرینتر را گرفته → `sudo modprobe -r usblp`.
- `توکن نامعتبر`: `AGENT_TOKEN` را دوباره از تنظیمات کپی کنید.
- چیزی چاپ نمی‌شود ولی صف پر است: ابتدا `PRINTER_TYPE=file` را امتحان کنید تا مطمئن شوید سند ساخته می‌شود؛ سپس اتصال پرینتر را بررسی کنید.
- متن فارسی جعبه‌جعبه است: فونت درست بارگذاری نشده؛ مسیر `FONT_REGULAR` را بررسی کنید.
- QR چاپ نمی‌شود: مدل پرینتر دستور بومی `qr` را پشتیبانی نمی‌کند؛ در این صورت به من بگویید تا QR را به‌صورت تصویر داخل سند بگنجانم.
